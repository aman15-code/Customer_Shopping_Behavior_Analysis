# Customer Shopping Behavior Analysis
## Overview
This project analyzes customer shopping behavior using transactional purchase data to identify spending patterns, customer segments, and product preferences. The analysis combines Python for data exploration, SQL for business analysis, and Power BI for data visualization. The goal is to generate insights that can help businesses make better marketing and sales decisions.

## Dataset
The dataset contains customer purchase information including demographics, product details, and shopping behavior. It includes fields such as:
- Age and Gender
- Item Purchased
- Product Category
- Purchase Amount
- Shipping Type
- Discount Applied
- Review Rating
- Purchase Frequency
- Subscription Status
The dataset is used to analyze customer spending behavior and identify trends across different customer groups.

## Tools and Technologies
The following tools and technologies were used in this project:
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook
- SQL (MySQL)
- Power BI

## Project Steps

### 1. Data Loading
The dataset was loaded into Python using the Pandas library for analysis.
### 2. Data Cleaning
Data cleaning included handling missing values, removing redundant columns, and standardizing column names.
### 3. Exploratory Data Analysis (EDA)
Exploratory analysis was performed to understand data patterns, distributions, and relationships between variables.
### 4. SQL Analysis
The cleaned dataset was imported into a SQL database. SQL queries were written to answer business-related questions such as revenue comparison, customer segmentation, and product performance.
### 5. Dashboard Creation
An interactive Power BI dashboard was created to visualize important insights such as customer demographics, product performance, and sales trends.
## Dashboard
The Power BI dashboard provides visual insights including:
- Sales and revenue trends
- Customer demographic analysis
- Product category performance
- Customer purchase behavior

## Results and Insights
Key insights from the analysis include:
- Identification of high-spending customer segments
- Understanding the most popular product categories
- Revenue contribution from different customer groups
- Impact of discounts and shipping types on purchases

These insights can help businesses improve marketing strategies and customer engagement.
